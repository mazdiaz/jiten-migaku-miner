# Phase 3: Simplify UI + Accessibility — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Audit Phase 3 (less configuration on screen, clearer modes/entry hierarchy, mobile layout, honest copy) + Phase 4 "Other Accessibility Changes", plus Wave-2 carry-overs. Preserve the dark palette, Japanese-text emphasis, and Migaku-compatible sentence rendering (audit Phase 3 preamble).

**Architecture:** The sticky toolbar becomes THE one toolbar (compact row: title, search, queue, pager, Filters disclosure). The top filters-panel's controls move into a collapsible advanced panel behind that disclosure, split into named Filters vs Display groups; duplicated sticky row-2 controls are deleted (single source of truth per control, surviving IDs are the top-panel set). Import panel collapses to a summary + Change Files after load. Entry rendering reorders to target/badges → sentence → definition → compact actions with controls outside the sentence DOM. No framework changes; DOM edits in index.html + DomMap + renderer/controls sync + CSS.

**Tech Stack:** TypeScript, Vite, Vitest (happy-dom), Playwright Chromium (mobile viewport specs added).

**Spec:** `DL/WEBSITE-IMPROVEMENT-AUDIT.md` Phase 3 + Phase 4 "Other Accessibility Changes" (lines 121-203).

## Global Constraints

- Preserve dark palette (--bg/--surface families), Japanese emphasis (Yu Mincho sentences, lang="ja" on Japanese text), Migaku-compatible sentence rendering (highlight adapter untouched).
- Failing regression (unit or e2e) before each behavioral/structural change; CSS-only polish may verify via e2e assertion instead.
- E2E selector compatibility: specs reference both top-panel IDs (#sortSelect, #showFurigana, …) and sticky duplicates (#stickySort, #stickyFurigana, …). Tasks removing duplicates MUST update affected specs to the surviving IDs in the same commit (grep `tests/e2e/*.spec.ts` for each removed ID).
- `npm run check` + `npm run test:e2e` green at wave end. Unit + e2e counts grow.
- Conventional commits.
- Audit layout targets (fixture-dependent, directional): desktop first entry near initial viewport (today ~1014px down); mobile sticky toolbar far below 359px/~44vh (single compact row + collapsible).
